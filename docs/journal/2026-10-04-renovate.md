### D-101 · Renovate configuration (autopilot)

- **Decision:** Extend `config:best-practices`, which pins Action digests and devDependencies, maintains the lockfile weekly and applies a minimum release age for npm. Then add:
  - semantic commits;
  - a Monday-morning schedule (Asia/Colombo);
  - a 3-day minimum release age for every manager;
  - grouped non-major development updates, and grouped Actions updates;
  - dependency-dashboard approval for every major update;
  - Expo-managed packages disabled;
  - the `type: dependencies` label, plus `type: security` on vulnerability fixes.

  (autopilot)

- **Why:**
  - Major updates are where incompatibilities live (D-41), so a person decides when to take them.
  - Expo pins compatible versions per SDK, so bumping single packages breaks builds.
  - Grouping keeps PR noise down for a single maintainer.
