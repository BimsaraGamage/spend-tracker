# Getting help

| Need | Where |
| --- | --- |
| A question about using or developing spend-tracker | [Discussions → Q&A](https://github.com/BimsaraGamage/spend-tracker/discussions/categories/q-a) |
| An idea or feature discussion | [Discussions → Ideas](https://github.com/BimsaraGamage/spend-tracker/discussions/categories/ideas) |
| A reproducible bug | [Open a bug report](https://github.com/BimsaraGamage/spend-tracker/issues/new/choose) |
| A security vulnerability | Report it privately, as described in [SECURITY.md](SECURITY.md) |

This is a volunteer-maintained project, so there is no guaranteed response time. Please never post real financial data or personal information.
